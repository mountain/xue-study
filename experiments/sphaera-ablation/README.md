# sphaera-ablation：把旧观测与新观测做成消融对，接上季节预报

**起自** `sphaera-frame` README 末句自己写下的那一问：

> whether the added channel carries information about a specified future
> monthly/seasonal target **after conditioning on the original channel, season
> and slow-variable baselines**. The old and new observers should remain
> available as an **ablation pair**.

**数据**（提问方 2026-10-08 选定 C）：R1 + 月平均，`u/v` 在 250/500/850 hPa，
**1979-01 … 2025-12，564 个月** —— 与链式外推的 `development_backtest` **同一个窗口**。

## 已跑通的链路

```
R1 月平均 u/v (2.5° 网格, 73×144)
  → 双线性插值到 sphaera 的 16 个声明节点
  → 转成笛卡尔切向分量 (u_x, u_y, u_z)
  → request.json（564 case × 48 输入）
  → 【真正的 adva-lisp kernel】求值
  → 每月一个 (E, O)
```

```
native functions=12, evaluations=564, bytes=3254295, exit 0
runs/run-001/{request.json, native.json, eo.npz}
```

## 读数（850 hPa，564 月）

```
E  sd ?            范围 ?
O  均值 +3.3423    sd 0.3788    范围 [+2.4208, +4.2559]
corr(E, O) = +0.5830        ← 相关但不共线 ⇒ 消融不是退化的
```

**两者都有强季节循环：**

```
6–8 月   E 最负 (−2.44 … −2.72)   O 最低 (+2.93 … +3.05)
11–1 月  E 最接近 0 (−0.94 … −0.97)  O 最高 (+3.64 … +3.77)
```

⇒ **季节循环主导**。所以消融**必须去掉季节循环**，或把「季节」作为基线预测子 ——
这正是 `sphaera-frame` 那句「after conditioning on ... season」的意思。

## 两处被契约挡住、已按规矩解决

1. **求值预算**：探针 `main.rs:36` 写死 `cases.len() > 512` 即拒；而契约的
   `evaluations: 512` 与之对应。**564 > 512 ⇒ 被拒**。
   **本实验自带探针与契约**（`src/main.rs` 把上限提到 4096 并写明理由），
   **不改 `sphaera-frame` 已冻结的探针**。
2. **写死的对照要求完整函数集**：探针无条件求值 `compiled["turn-i"]`，
   只声明 `["spectrum"]` 会 panic（`no entry found for key`）。
   ⇒ request 必须声明全部 12 个导出；只有 `spectrum` 带 case。

## 一处**未消解**的几何缺口（必须与读数同时出现）

声明节点纬度是 **asin(3/5)=36.87°** 与 **asin(4/5)=53.13°**，
而 R1 月平均的 2.5° 网格上是 **37.5°** 与 **52.5°**，差 **0.63°**。

**程序里烤死的权重对应 z=±3/5, ±4/5，采样点实际在 z=±0.6088 / ±0.7986 上。**
本件用双线性插值逼近，**但插值不消除这个落差**。经度方向恰好落在网格上（0/90/180/270），无需插值。

## 尚未做

- **消融本身**（目标变量、去季节、时序外样本、E vs E+O 的技巧比较）**未做**。
- 只跑了 850 hPa；250/500 hPa 未跑。
- 未做 ERA5（选项 D）的对比 —— 见下。

## 消融结果（2026-10-08）：**否定，而且不需要走 D**

**目标**：t+2 的 Niño 3.4 异常（ERSST v5，5S–5N / 190–240E，130 格）。
**去季节**：各自减去**训练期**（1979-01…2009-12）的月气候态。
**外样本**：训练 372 月，测试 190 月。

```
模型              参数   test corr   test RMSE   对气候态技巧
M0 气候态           1       nan       0.8879      -0.0000
M1 E               2     0.1116      0.8878       0.0001
M2 E+O             3    -0.0042      0.8884      -0.0006
M3 E+SST           3     0.8746      0.4314       0.5141
M4 E+O+SST         4     0.8758      0.4292       0.5166

主判据 M2−M1   corr 0.1116 → −0.0042  (Δ −0.1158)   ← O 让事情变差
次判据 M4−M3   corr 0.8746 →  0.8758  (Δ +0.0012)   ← 几乎无增量
```

**M3（E + 持续性）的技巧 0.5141 几乎全部来自持续性本身。** E 单独对气候态的技巧是 **0.0001**。

### 诊断：不是「没有提前量」，是「根本没有关系」

```
k     E vs N34(t+k)   O vs N34(t+k)
0         0.0345          0.0147
1         0.0426         -0.0108
2         0.0391         -0.0285
6         0.0254         -0.0981
12        0.0203         -0.0762
```

**包括同期（k=0）在内，所有 |r| < 0.11，多数 < 0.05。**
⇒ 16 个中纬度节点的 850 hPa 风，与热带海温**在任何一个提前量上都没有关系**。
「O 无增量」是「两者都无关系」的一个特例，不是通道结构的问题。

### 一处更正（我先前的说法不准确）

README 前面写「corr(E,O)=+0.5830，相关但不共线 ⇒ 消融不退化」。**那是带季节循环的相关系数。**

```
去季节前 corr(E,O) = +0.5830
去季节后 corr(E,O) = +0.0782      ← 几乎独立
```

**⇒ 那个 0.583 几乎全部是两个通道共享的季节循环。** 在消融真正所在的异常空间里，
E 与 O 近乎独立 —— **但两者各自都不携带关于目标的信息**。

### 结论：**不走 D（ERA5）**

三条理由：

1. **否定结果不是采样几何造成的。** 0.63° 的纬度缺口改变权重约 **1.5%**；
   而相关系数是 **0.03** 量级。**缺口不可能是一个 0.03 的成因。**
2. **E 与 O 在同期就没有关系**（0.0345 / 0.0147）。若问题出在采样精度，
   同期相关不该也接近零。
3. **D 能改的是「把一个没有信号的量测得更准」。** 更细的网格不会造出信号。

**⇒ 若要继续这条线，该改的不是采样，是【用什么风场、在哪个层次、取哪个区域】。**

### 顺带发现的一处元数据不一致（记录，不修）

`sst.npz` 的边车 `source_units` 写 **`degC`**，但实际取值在 **297.7–302.6** ——
**那是开尔文，不是摄氏度**。（ERSST v5 的原始月平均确实是 °C，量级 −1.8…32。）

**本消融不受影响**：去季节后的异常在 K 与 °C 下数值相同。
但这正是本项目反复记录的那一类 —— **声明的单位与实际的量不符**。

### 边界

- 只测了 **Niño 3.4 一个目标**、**850 hPa 一个层次**、**k=2 一个提前量**
  （诊断里补了 k=0..24，但消融模型只建了 k=2）。
- 只用线性回归。非线性关系未测 —— **但同期相关接近零时，非线性也难有立足处**。
- 训练/测试只取了一个切分（2009-12 为界）。未做滚动或多种切分。
- 气候态与回归系数都只用训练期（避免未来信息泄漏），但**切分点本身是选定的**。
