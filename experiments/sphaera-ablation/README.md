# sphaera-ablation：把旧观测与新观测做成消融对，接上季节预报

**起自** `sphaera-frame` README 末句自己写下的那一问：

> whether the added channel carries information about a specified future
> monthly/seasonal target **after conditioning on the original channel, season
> and slow-variable baselines**. The old and new observers should remain
> available as an **ablation pair**.

**数据**（提问方 2026-10-08 选定 C）：R1 + 月平均，`u/v` 在 250/500/850 hPa，
**1979-01 … 2025-12，564 个月** —— 与链式外推的 `development_backtest` **同一个窗口**。

## 已跑通的链路

```
R1 月平均 u/v (2.5° 网格, 73×144)
  → 双线性插值到 sphaera 的 16 个声明节点
  → 转成笛卡尔切向分量 (u_x, u_y, u_z)
  → request.json（564 case × 48 输入）
  → 【真正的 adva-lisp kernel】求值
  → 每月一个 (E, O)
```

```
native functions=12, evaluations=564, bytes=3254295, exit 0
runs/run-001/{request.json, native.json, eo.npz}
```

## 读数（850 hPa，564 月）

```
E  sd ?            范围 ?
O  均值 +3.3423    sd 0.3788    范围 [+2.4208, +4.2559]
corr(E, O) = +0.5830        ← 相关但不共线 ⇒ 消融不是退化的
```

**两者都有强季节循环：**

```
6–8 月   E 最负 (−2.44 … −2.72)   O 最低 (+2.93 … +3.05)
11–1 月  E 最接近 0 (−0.94 … −0.97)  O 最高 (+3.64 … +3.77)
```

⇒ **季节循环主导**。所以消融**必须去掉季节循环**，或把「季节」作为基线预测子 ——
这正是 `sphaera-frame` 那句「after conditioning on ... season」的意思。

## 两处被契约挡住、已按规矩解决

1. **求值预算**：探针 `main.rs:36` 写死 `cases.len() > 512` 即拒；而契约的
   `evaluations: 512` 与之对应。**564 > 512 ⇒ 被拒**。
   **本实验自带探针与契约**（`src/main.rs` 把上限提到 4096 并写明理由），
   **不改 `sphaera-frame` 已冻结的探针**。
2. **写死的对照要求完整函数集**：探针无条件求值 `compiled["turn-i"]`，
   只声明 `["spectrum"]` 会 panic（`no entry found for key`）。
   ⇒ request 必须声明全部 12 个导出；只有 `spectrum` 带 case。

## 一处**未消解**的几何缺口（必须与读数同时出现）

声明节点纬度是 **asin(3/5)=36.87°** 与 **asin(4/5)=53.13°**，
而 R1 月平均的 2.5° 网格上是 **37.5°** 与 **52.5°**，差 **0.63°**。

**程序里烤死的权重对应 z=±3/5, ±4/5，采样点实际在 z=±0.6088 / ±0.7986 上。**
本件用双线性插值逼近，**但插值不消除这个落差**。经度方向恰好落在网格上（0/90/180/270），无需插值。

## 尚未做

- **消融本身**（目标变量、去季节、时序外样本、E vs E+O 的技巧比较）**未做**。
- 只跑了 850 hPa；250/500 hPa 未跑。
- 未做 ERA5（选项 D）的对比 —— 见下。

## 消融结果（2026-10-08）：**否定，而且不需要走 D**

**目标**：t+2 的 Niño 3.4 异常（ERSST v5，5S–5N / 190–240E，130 格）。
**去季节**：各自减去**训练期**（1979-01…2009-12）的月气候态。
**外样本**：训练 372 月，测试 190 月。

```
模型              参数   test corr   test RMSE   对气候态技巧
M0 气候态           1       nan       0.8879      -0.0000
M1 E               2     0.1116      0.8878       0.0001
M2 E+O             3    -0.0042      0.8884      -0.0006
M3 E+SST           3     0.8746      0.4314       0.5141
M4 E+O+SST         4     0.8758      0.4292       0.5166

主判据 M2−M1   corr 0.1116 → −0.0042  (Δ −0.1158)   ← O 让事情变差
次判据 M4−M3   corr 0.8746 →  0.8758  (Δ +0.0012)   ← 几乎无增量
```

**M3（E + 持续性）的技巧 0.5141 几乎全部来自持续性本身。** E 单独对气候态的技巧是 **0.0001**。

### 诊断：不是「没有提前量」，是「根本没有关系」

```
k     E vs N34(t+k)   O vs N34(t+k)
0         0.0345          0.0147
1         0.0426         -0.0108
2         0.0391         -0.0285
6         0.0254         -0.0981
12        0.0203         -0.0762
```

**包括同期（k=0）在内，所有 |r| < 0.11，多数 < 0.05。**
⇒ 16 个中纬度节点的 850 hPa 风，与热带海温**在任何一个提前量上都没有关系**。
「O 无增量」是「两者都无关系」的一个特例，不是通道结构的问题。

### 一处更正（我先前的说法不准确）

README 前面写「corr(E,O)=+0.5830，相关但不共线 ⇒ 消融不退化」。**那是带季节循环的相关系数。**

```
去季节前 corr(E,O) = +0.5830
去季节后 corr(E,O) = +0.0782      ← 几乎独立
```

**⇒ 那个 0.583 几乎全部是两个通道共享的季节循环。** 在消融真正所在的异常空间里，
E 与 O 近乎独立 —— **但两者各自都不携带关于目标的信息**。

### 结论：**不走 D（ERA5）**

三条理由：

1. **否定结果不是采样几何造成的。** 0.63° 的纬度缺口改变权重约 **1.5%**；
   而相关系数是 **0.03** 量级。**缺口不可能是一个 0.03 的成因。**
2. **E 与 O 在同期就没有关系**（0.0345 / 0.0147）。若问题出在采样精度，
   同期相关不该也接近零。
3. **D 能改的是「把一个没有信号的量测得更准」。** 更细的网格不会造出信号。

**⇒ 若要继续这条线，该改的不是采样，是【用什么风场、在哪个层次、取哪个区域】。**

### 顺带发现的一处元数据不一致（记录，不修）

`sst.npz` 的边车 `source_units` 写 **`degC`**，但实际取值在 **297.7–302.6** ——
**那是开尔文，不是摄氏度**。（ERSST v5 的原始月平均确实是 °C，量级 −1.8…32。）

**本消融不受影响**：去季节后的异常在 K 与 °C 下数值相同。
但这正是本项目反复记录的那一类 —— **声明的单位与实际的量不符**。

### 边界

- 只测了 **Niño 3.4 一个目标**、**850 hPa 一个层次**、**k=2 一个提前量**
  （诊断里补了 k=0..24，但消融模型只建了 k=2）。
- 只用线性回归。非线性关系未测 —— **但同期相关接近零时，非线性也难有立足处**。
- 训练/测试只取了一个切分（2009-12 为界）。未做滚动或多种切分。
- 气候态与回归系数都只用训练期（避免未来信息泄漏），但**切分点本身是选定的**。

## 「换风场／层次／区域」（2026-10-08）：**症结是区域，不是层次**

上一轮的否定结果用的是 `sphaera-frame` 声明的几何（4 个方位 × 4 个中纬度环）。
本轮把三处可改的都试了。**只有一处改得动结论，而且它改过来了。**

### 层次：三个都试了，**不是症结**

```
几何      层次   corr(E,O)   M1(E)corr   M2(E+O)corr   M2技巧
declared  250     +0.7702     −0.1142      −0.0117      −0.015
declared  500     +0.8128     +0.1699      −0.0063      −0.006
declared  850     +0.5830     +0.1116      −0.0042      −0.001
```

三个层次上 O 加进去都**变差**。250 hPa 有理论动机（涡度信号更强），实测没有帮助。

### 区域：**这一处改得动，而且改过来了**

节点表由**生成器** `adva_source(nodes)` 决定，不依赖数据，所以换一组节点就是另一份合法程序。
热带变体把内两环放到 **z=±5/13（纬度 ±22.62°）**，外两环保持 z=±3/5（±36.87°）。

```
几何      层次   M1(E) corr/skill    M2(E+O) corr/skill   M2−M1 Δcorr
tropical  250    0.0095 / 0.0001     0.2241 / 0.0249       +0.2146
tropical  500    0.1116 / 0.0058     0.2306 / 0.0257       +0.1190
tropical  850    0.1005 / 0.0053     0.1525 / 0.0097       +0.0420
```

**加上 O 之后相关系数大致翻倍，技巧提升约 4–20 倍。**

### 稳健性：四组切分点全部一致

```
=== 热带几何 500 hPa ===            === 声明几何 500 hPa（对照）===
split  M1        M2        M4−M3    split  M1        M2        M4−M3
1999  0.0852   0.2450    +0.0055    1999  0.0858   0.0435    +0.0002
2004  0.0731   0.2299    +0.0060    2004 −0.1357  −0.0187    +0.0008
2009  0.1122   0.2276    +0.0053    2009  0.1683  −0.0070    +0.0012
2014  0.0748   0.1767    +0.0050    2014  0.2062   0.0978    +0.0008
```

- **热带几何：四组 M2−M1 全为正**（+0.10…+0.14）；**M4−M3 也全为正**（+0.0050…+0.0060）
- **声明几何：四组里有三组 M2 比 M1 差**，技巧为负

**⇒ 上一轮的否定结果是【区域】造成的，不是层次、不是通道结构、更不是分辨率。**

### 但必须同时说的三条

1. **绝对技巧仍然很小。** M2 对气候态的技巧 **0.025–0.031** —— 这不是可用的预报，
   只在「O 是否携带 E 之外的信息」这个问句上有意义。
2. **提升主要来自 M2（E+O 联合），不是来自 O 单独。** E 单独在最优点也只有 0.006。
3. **一处设计限制被实测出来**：程序的算术是**有理数**，节点必须是**单位向量且坐标有理**，
   故 z 只能取勾股数。**能到的最小 |z| 是 5/13（纬度 22.62°）—— 无法更靠近赤道。**
   要真正进入热带需要放弃有理算术，那是另一件工程。

### 结论：**仍然不走 D**

**改善来自几何，不来自分辨率。** ERA5 的 0.25° 网格能让节点纬度**精确落上**，
但它改的是采样精度 —— 而本轮证明决定性的变量是**采样位置**。
先把位置调对，再谈精度。

### 边界

- 热带变体**不是** `sphaera-frame` 声明的几何。两者**不可互相引用**，
  本 README 里凡出现 `declared` 与 `tropical` 都分别标注。
- 仍只测 Niño 3.4、k=2、线性模型；切分点从 1 个扩到 4 个，但仍未做滚动评估。
- 热带变体只动了 z（纬度），经度仍是 0/90/180/270 四个方位。

## 方位加密到勾股角集合（2026-10-08）：**没有改善，这是这条线的收束**

### 加密是合法的，但只能加在勾股角上

单位圆上的有理点为 `(x,y)=((1−t²)/(1+t²), 2t/(1+t²))`，t 有理 ⇒ 方位角只能取 `2·atan(t)`：
**0°、36.87°、53.13°、90°、…**。**均匀加密需要 √2，不合法。**

本件取 8 个方位（4 基本 + 4 勾股对角），4 环 ⇒ **32 节点**。
`dense` 几何的纬度与 `tropical` 相同（±22.62°、±36.87°），只有方位加密。

```
tropical4  16 节点, 48 输入/案,  request 779,729 B
dense8     32 节点, 96 输入/案,  request 1,538,921 B
```

### 结果：没改善

```
几何        M1(E)    M2(E+O)   M2−M1     M4−M3 corr   M4−M3 RMSE
tropical4  0.1116    0.2306    +0.1190     +0.0050      −0.0047   ← corr 与 RMSE 都变好
dense8     0.1207    0.2629    +0.1422     +0.0023      +0.0066   ← corr 好、RMSE 变差
```

**M2−M1 略有增大（+0.119 → +0.142），但 M4−M3 变弱，且 RMSE 反向（+0.0066）。**
⇒ **在这个判据上，加密方位没有带来可辨的改善。**

### 为什么，以及这条线的收束

**加密只能在勾股角上做，而那本身就不均匀**：0°、36.87°、53.13°、90° —— 前三者挤在 90° 内，
后两者之间跨 36.87°。**所以 8 个方位并没有比 4 个覆盖得更均匀**，只是多插了几个
本来就在的方向附近。

配合前一轮实测出的另一个约束，得到这条线的**合并结论**：

> **这套 native 构造（有理算术 + 单位球面）在结构上有两个硬约束：**
>
> 1. **纬度**：节点须是单位向量且坐标有理 ⇒ z 只能取勾股数
>    ⇒ **|z| 最小 5/13（纬度 22.62°），无法更靠近赤道**
> 2. **经度**：方位角同理 ⇒ **只能取勾股角，均匀加密不合法**
>
> **⇒ 它无法给出热带的一个均匀采样，而且这不是实现问题，是设计的两条边界。**

### 一处自我更正

`extract_nodes.py` 的打印里 `48 个输入` 是**写死的**，而 32 节点时实际是 96。
（文件大小证实：`dense` 的 request 是 1,538,921 B，约为 `tropical` 的 1.98 倍 ⇒ 确实翻了倍。）
**打印与实际不符，已记下；两者我都没有当成读数用。**

- 只做了 500 hPa 的消融；250/850 的 `native.json` 已产出（各 5.8 MB）但**未消融**。

## 换目标（2026-10-08）：高原目标上 O 的增量小，但在持续性之上更稳

**沿用热带几何 500 hPa、k=2、训练 ≤ 2009。** 每个通道用**它自己的** lat/lon。

```
目标                         M1 E     M2 E+O   M2−M1    M3 E+SST    M4      M4−M3
sp   高原 28-36N/80-100E   −0.0138  −0.0113  +0.0025    0.0368   0.0476  +0.0108
t2m  高原 28-36N/80-100E    0.1137   0.1175  +0.0038    0.5684   0.5780  +0.0096
z500 高原 28-36N/80-100E    0.0098   0.0125  +0.0027    0.0417   0.0551  +0.0134
msl  高原 28-36N/80-100E   −0.0483  −0.0888  −0.0405    0.4712   0.4664  −0.0047
sp   全球                  −0.1395  −0.0471  +0.0924    0.0545   0.0143  −0.0402
z500 全球                  −0.0334   0.0407  +0.0741    0.2875   0.2839  −0.0036

（对照：Niño3.4    M1 0.1116  M2 0.2306  M2−M1 +0.1190  M3 0.8754  M4 0.8804  M4−M3 +0.0050）
```

### 模式

| 目标族 | M2−M1（O 单独） | M4−M3（持续性之上） |
|---|---|---|
| 海温 Niño3.4 | **+0.119**（大） | +0.0050 |
| 高原四目标 | **+0.003 … −0.041**（小，msl 为负） | **+0.010 … +0.013**（除 msl） |
| 全球两目标 | **+0.074 … +0.092**（大） | **−0.040 … −0.004**（负） |

**⇒ 两个方向相反的族：全球目标上 O 单独有用、加上持续性反而有害；
高原目标上 O 单独几乎无用，但加上持续性后一致为正（msl 例外）。**

**这与「O 是水平项、E 是偶极项」的分工是一致的**：O 携带的是区域尺度上的一致性信息，
在持续性基线之上才显出价值。

### **一处我必须自己指出的重叠**（可能影响高原目标的可解释性）

采样纬度是 **±22.62° 与 ±36.87°**，而**高原框是 28–36°N** ——
**36.87° 落在框内**。所以「用 36.87° 的风预测高原」在空间上是**邻接**的，
相关系数里可能混着**同期空间连续性**，而不全是两个月提前量的预报信息。

**本件有 k=2 的提前量，所以不是同期；但「邻接」这一条使高原目标的解释力弱于 Niño3.4。**
要排除它需要在**高原纬度之外**采样 —— 而那又撞上前面那两条硬边界。

### 边界

- **绝对数值都很小**（最好 M4−M3 = +0.0134）。**这不是可用的预报。**
- 目标只有 6 个，都取自 R1/ERSST 的现成通道；未做区域或层次的敏感性扫描。
- 单一切分（train ≤ 2009-12）、线性模型、k=2。
- 预报子全部来自**热带几何 500 hPa**；未换几何重跑这些目标。

---

## MJO 方向：把目标换成月度 MJO 指标（2026-10-08）

**这一步回答的是**：热带外采样携带的，是热带变率的**同期**签名，还是**超前**信息？

### 指标怎么来的，以及它不是什么

RMM 的构造是赤道带平均的 **OLR + 850 hPa 纬向风 + 200 hPa 纬向风**联合 EOF 的前两主成分。
我们的资料**没有 OLR**，但有 u850/u250，所以取：

```
PC = 赤道带 (15S–15N, cos φ 面积权重) 平均的 [u850', u250'] 联合 EOF 前两主成分
     去季节的气候态只用训练期（≤2009）
```

**这是 RMM 的【风场部分】，不是 RMM。** 少一支 OLR，对流中心定位会差。
**而月平均滤掉 30–90 天频带的大部分**，留下的是 MJO 的**活动包络**、不是相位。
⇒ 本件问的是「**月度** MJO 活动可否从热带外采样预测」，**不是**「能否预测 MJO 相位」。

### 结果

```
联合 EOF 前两主成分解释方差: 19.8% + 13.6% = 33.4%

目标          M1 E     M2 E+O   M2−M1     M3 E+PC(t)    M4      M4−M3
MJO-PC1     0.0795   0.2474   +0.1679     0.7224     0.7234   +0.0009
MJO-PC2    −0.0152   0.1151   +0.1302     0.2320     0.2304   −0.0016

对照 Niño3.4 (k=2)  M1 0.1116  M2 0.2306  M2−M1 +0.1190  M4−M3 +0.0050
```

### 两条读数，方向相反，合起来是结论

**① O 在 E 之上的增量，对 MJO 比对照 Niño3.4 更大**
（+0.1679 / +0.1302 对 +0.1190）。⇒ **热带外采样确实携带与 MJO 有关的信息**，
而且比与热带海温的更强 —— 与「MJO 的罗斯贝涡旋直接伸到 ±20–30°」这一图像一致，
而 ENSO 的热带外签名要靠更长的波列。

**② 但加上持续性（PC(t)）之后，O 的增量归零甚至转负**
（+0.0009 / −0.0016）。而 PC1 的持续性很强（M3 = 0.7224）。

> **⇒ 热带外采样携带的是热带变率的【同期】签名，不是【超前】信息。**
> 知道了当年的 PC，热带外风场在两个月提前量上不再提供任何东西。

**这在物理上是自洽的**：MJO 的罗斯贝涡旋对**本身就是 MJO 结构的一部分**，
不是它的前兆。所以它们**按构造**与 MJO 同期，不领先。

### 由此对「热带内外分离」这个问题的回答

**我们的方法没有突破那条边界 —— 它显示那条边界在【预测】意义上是实的。**
传统上把 MJO 与热带外分开**不是分析上的偷懒**：两者的**同期**耦合很强（本件实测），
但热带外的部分**不携带独立的提前量**。分开讨论之所以成立，
是因为**热带外那半边是被动响应的一方**。

**⇒ 「用热带外的量预测热带」这条路，在本采样与本窗口下，即使对 MJO 也不成立** ——
不是因为信息不存在，而是因为那份信息**与热带自身的持续性共线**。

### 边界

- **月平均**，故只涉及 MJO 的活动包络，不涉及相位。
- 指标**缺 OLR 一支**，是 RMM 的近似。
- 单一切分（train ≤ 2009-12）、线性模型、k=2。
- 预测子仍来自**热带几何 500 hPa**；未换几何或层次重跑本目标。
- **绝对数值仍小**（M2 最好 0.2474）—— 这不是可用的预报。
