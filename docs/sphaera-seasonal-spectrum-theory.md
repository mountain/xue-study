## 2. 代码定义的谱

`spectrum.py` 为每个候选轴构造模板，再与风场做归一化加权内积。
`perp = r - (a·r)a` 后取 `a × perp`，代数上就是 `a × r`。
`signature = sign(a·r)` 随后把两个半球的模板方向翻转。

在下列**理想化前提**下可以得到一个明确的连续算子：

- `r`、`a` 是单位球面上的位置和候选轴；
- 风 `u(r)` 已转换为同一笛卡尔坐标系中的切向量；
- 积分使用完整球面、正确面积权重，无掩膜；
- 球壳半径和厚度固定，代码中的体积权重归一化后等价于面积权重。

\[
k_a(r)=\operatorname{sgn}(a\cdot r)(a\times r),\qquad
S_u(a)=\frac1{4\pi}\int_{S^2}u(r)\cdot k_a(r)\,d\Omega.
\]

这个谱的自变量是**轴向**，谱值是有符号的速度投影，单位仍为 m/s。
代码没有定义时间频率、正交能量分解或未来演化方程。
空间模板覆盖全球，并不推出它对应一个随时间缓慢演化的模态。

`examples/wind.nc` 的 NetCDF 头部本轮用标准库直接读取：
`u10/v10` 的维度为 `(time, latitude, longitude) = (1, 721, 1440)`，
纬度由 90 到 −90，经度由 0 到 359.75，时间为 **2018-12-30 00:00 UTC**。
因此示例数据本身只有一个时刻，不能据此识别任何时间周期或预报时效。
`finder.py` 的学习对象是随机球面路径上的几何一致性与拉普拉斯约束，
它没有使用带未来气象标签的时间序列，不能作为已训练气象预测器的证据。

## 3. 这个观测算子的可辨识性

### 3.1 相反的轴是同一个观测

\[
k_{-a}(r)=k_a(r),\qquad S_u(-a)=S_u(a).
\]

因此轴向空间自然具有 `a ~ -a` 的对径等价关系。
谱图上的一对对径峰不能计作两个独立结构。
另外，`k_a(-r)=k_a(r)`，所以任何满足 `u(-r)=-u(r)` 的向量场都会被积分消去。

一个明确反例是刚体式旋转：

\[
u(r)=\Omega\times r\ne0,\qquad S_u(a)=0\quad\text{对所有 }a.
\]

零风场和这个非零风场有相同的完整谱。单次谱不可能唯一重建一般风场。
这不直接否定预报用途：仍须检验被消去的区别是否影响指定目标。

### 3.2 纯梯度分量也不可见

设 `f_a(r)=|a·r|`，在单位球面上有

\[
k_a=-r\times\nabla_S f_a.
\]

它是球面无散模板；绝对值在大圆处的折点可以按弱导数处理。
对足够光滑的切向风场，球面分部积分给出

\[
S_u(a)=\frac1{4\pi}\int_{S^2}|a\cdot r|\,\zeta_S(r)\,d\Omega,
\]

其中 `ζ_S` 是单位球面坐标下的径向旋度。
若使用物理半径 `R` 上单位为 s⁻¹ 的相对涡度，右侧须再乘 `R`，使单位一致。
于是当 `u=∇_S χ` 时，`S_u=0`。

结合球面分解 `u=∇_S χ+r×∇_S ψ`，这个算子只观察旋转分量中的一部分。
对降水或水汽输送目标，是否需要另行保留辐合和水汽变量，应成为明确的检验问题。

### 3.3 与球谐阶数的关系

核 `|a·r|` 是旋转对称的球面卷积核。在通常的球谐展开约定下，其乘子为

\[
\beta_\ell=\frac12\int_{-1}^{1}|x|P_\ell(x)\,dx,\qquad
(S_u)_{\ell m}=\beta_\ell(\zeta_S)_{\ell m}.
\]

奇数阶乘子全部为零。对旋转势 `ψ`，因 `ζ_S=Δ_S ψ`，乘子是
`−ℓ(ℓ+1)β_ℓ`。零阶涡度在完整闭合球面上积分为零。

| ℓ | 涡度到谱的乘子 βℓ | 旋转势到谱的乘子 |
| --- | --- | --- |
| 0 | 1/2 | 0 |
| 1 | 0 | 0 |
| 2 | 1/8 | −3/4 |
| 3 | 0 | 0 |
| 4 | −1/48 | 5/12 |
| 5 | 0 | 0 |
| 6 | 1/128 | −21/64 |
| 7 | 0 | 0 |
| 8 | −1/256 | 9/32 |

表中数值用 Legendre 递推和 Python `Fraction` 精确积分核对。
这给出了从原谱扩展的具体方向：保留原观测，按目标需要补充奇数阶旋转和梯度通道。
仅仅去掉 `sign` 只能得到一阶整体旋转的观测，不能恢复所有缺失模态。

一种可控的候选族是逐阶使用

\[
P'_\ell(a\cdot r)(a\times r),\qquad
P'_\ell(a\cdot r)\{a-(a\cdot r)r\},\quad1\le\ell\le L.
\]

两类分别观察旋转与梯度分量；`L` 是明确的有限预算与分辨率选择。
这只是候选扩展，是否比原谱更适合预报必须另验。

### 3.4 本轮合成核对及其限制

没有执行原始百万轴的双循环，也没有加载保存的 Torch 张量。
独立用标准库实现理想核，在等面积坐标 `(z, longitude)` 的中点网格上求积；
网格为 `40×80` 和 `80×160`，各检查 3 个轴。
风场包括刚体旋转、线性函数的球面梯度、以及 `ψ=P₂(z)`、`ψ=P₃(z)` 的旋转场。

- 两个网格上的刚体旋转和三阶旋转读数均在约 `4e-17` 以内；
- `ψ=P₂(z)` 的解析答案是 `−3/4 P₂(a_z)`；
  `a=e_z` 时数值为 `−0.7509375`、`−0.750234375`，解析值为 `−0.75`；
- 斜轴的纯梯度零响应在细网格仍有约 `4.8e-4` 的求积残差；
- 斜轴二阶场的误差没有在这两次细化中单调下降。

这些是有限合成算例，不能当作离散实现的完整验证或误差上界。
零空间的普遍结论来自上面的代数、对称性与分部积分推导。
原核带 `sign` 跳变，离散求积及其收敛需要专门校准。

## 4. 原代码与上述物理解读之间的缺口

下面两项由代码与文件头直接对照发现：

1. **风向量的坐标基没有对齐。** `thetaphir.r` 和叉积模板的分量是笛卡尔分量，
   `vec3.dot` 直接逐分量相乘。示例却令 `wnd=(u10,v10,0)`；
   `u10/v10` 表示局部向东、向北风，须先用
   `u_cart = u10 e_east + v10 e_north` 转换，或把模板投影回同一局部基。
   调用 `sph.use('xyz')` 本身不转换这个普通 tuple。
2. **经纬网格与输入数组的轴次序不一致。** `RegularGrid.data()` 把第一个空间轴 `L`
   作为 longitude，第二个 `W` 作为 latitude；输入却按 latitude × longitude 排列，
   示例给的是 `L=721,W=1504`。需要用文件坐标建立逐点映射，并同时核对接缝和面积权重。

因此上面的连续推导不是对仓库中 `spectrum.dat` 物理有效性的背书。
首轮应保留旧实现作为对照，检验转换后的切向性、旋转协变性、面积积分和解析场响应。
理论上的旋转协变也不表示地球动力学具有任意旋转对称性：自转轴、陆海分布和地形
会进入预测问题，表示的协变性与预测模型的物理对称性须分开。

## 5. 从瞬时谱到数月至半年的预测：缺的是状态与演化

用 `Q` 表示上述谱观测，`X_t` 表示完整耦合状态，`F_τ` 表示演化。
若要存在封闭的谱演化 `G_τ`，至少需要

\[
QX_1=QX_2\Longrightarrow QF_\tau(X_1)=QF_\tau(X_2).
\]

对于线性模型 `X'=AX`，一阶闭合要求 `ker Q` 对 `A` 不变。
若不可见分量会流入可见分量，就不能仅由当前谱确定下一个谱。
零空间存在本身还不证明真实大气不满足闭合；它给出了需要检验的条件。

一个说明观察历史作用的简单模型是 `q'=h, h'=−ω²q`：
只观察 `q`，同一个 `q₀` 配上相反的 `h₀` 会产生不同未来。
两个过去时刻的 `q` 在非退化采样条件下可以区分它们。
这是已知有限模型上的解释，不是把真实大气认作该振子。

候选预测状态因此可以是

\[
Z_t=(q_t,q_{t-\Delta},\ldots,q_{t-k\Delta},b_t,c_t),\qquad
\mathcal L(Y_{t+\tau}\mid Z_t),
\]

其中 `b_t` 是可用的慢变量，如海温、海洋热含量或陆面状态，`c_t` 是季节相位。
延迟历史和慢变量是否足够，要以目标条件分布及残差来检验；不能套用嵌入定理就宣布足够。

ECMWF 的季节预报说明把数月尺度的可预报性联系到较慢的地球系统变化，尤其 ENSO，
并以异常和概率为产品。这支持纳入慢变量的研究动机，不能保证本方法具有相同技巧。
[ECMWF seasonal forecasts](https://www.ecmwf.int/en/forecasts/documentation-and-support/seasonal)

目标可先选 1、3、6 个月提前量下的月平均温度异常或环流状态概率。
区域、变量、有效月、时间平均、基准气候态必须先固定。
若沿用高原问题，可首先讨论地面之上的 500 hPa 环流；不能把地下 850 hPa 外推
当成当地大气实况，也不能把大尺度环流技巧直接等同于冰川灾害技巧。

需要识别的是“哪些谱状态及其历史对未来仍有信息”。
空间尺度大不等于衰减慢；稳定的季节循环也不等于超越季节气候态的预测技巧。
确定性谱变换不会创造原始风场中没有的信息，但可能改善有限样本下的表示与估计。

## 6. 按 Adva 方法逐轮推进

Adva 的对应关系是：世界状态 `W` 经有限观察 `Q` 形成观测历史，学习结果先属于
`W/~Q` 的可辨识范围。一个值得保留的改进，应说明它排除了哪个候选，或增加了哪项
可检查能力。把同一批数据拟合得更好，不自动表示学到了世界结构。

| 轮次 | 一个明确问题 | 改变什么 | 可交付的证据 |
| --- | --- | --- | --- |
| 0：观测校准 | 实现是否计算声明的球面算子？ | 坐标基、轴序和积分实现 | 解析场、旋转协变、错误映射对照及求积残差 |
| 1：可辨识性 | 哪些不同状态被当前谱混在一起？ | 原谱与最少的补充通道 | 零空间见证、有限模态响应矩阵、未分辨部分 |
| 2：时间状态 | 当前谱是否足以描述目标的演化？ | 逐项加入历史或一个慢变量 | 过去信息加入前后的独立预测增益、残差结构 |
| 3：历史回报 | 1、3、6 个月是否超过基线？ | 固定容量的简单预测器 | 按年份分块的测试分数、概率校准、区间和失败年份 |
| 4：定向改进 | 哪一类失败与遗漏的观测有关？ | 每轮只改一种表示或前提 | 成对比较、消融、退步记录与适用边界 |

后续若执行实验，每轮再填写问题卡、数据版本、检查器、负对照和有限计算预算。
本文不启动自动搜索或训练，也不把这些待做项登记成已验证 claim。

最有区分力的负对照之一是：**保留月份，打乱不同年份的谱状态**。
若仍得到类似的“技巧”，模型可能只读出了季节，而没有利用当年的状态。
另一个对照是与相同特征数量、相同预测器的普通球谐/EOF 表示比较，
把表示贡献与模型容量分开。

基线至少包括训练期季节气候态、异常持续性，以及简单的海温/ENSO 预测器。
初始时间模型宜采用正则化线性或自回归模型，以便定位增益来源；
复杂模型作为后继候选，须有简单模型留下的具体残差作为动机。

## 7. 数据与验收边界

- 月至季节尺度需要跨多年的历史回报数据；本例单时刻风场和 xue-study 的短时归档
  都不足以回答这个问题。数据年份数不是独立样本数，季节与事件之间存在相关性。
- 切分按时间推进；训练标签的有效窗口不得越过模拟发布时刻。
  气候态、趋势、标准化、谱截断、EOF 和超参数都只在对应训练折内估计。
- 历史延迟只用过去值，不使用居中平滑引入未来资料。再分析与实时资料的可用时刻
  也须区分；只在再分析上成立的回报不等于可实时发布。
- 月平均与季节平均分开评分；重叠有效窗口不能当作独立样本。
  概率目标可用 Brier/CRPS 并报告可靠性，连续量同时报告误差与异常相关。
  不确定度按年份或事件分块估计，保留未参与调参的测试段。
- 短板通过消融定位：纯谱、谱加历史、谱加慢变量、慢变量单独使用，分别比较。
  如果增益全部来自海温，结论应归给海温；如果原谱即可达到同等技巧，保留更简单的观测。
- xue-study 当前检出没有 `archive/`。历史研究图和记录可以提供问题与反例，
  不能冒充本轮新取到的训练数据。

## 8. 相邻研究与仍未知的部分

NLSA 从时间历史的数据流形提取时空模态，已有工作将其与集合类比预测结合，
用于北太平洋海温、海冰的低频变化。它提供了“表示—历史—预测验证”的比较路线，
并不与本仓库的轴向风场积分相同，也不证明后者能预报半年。
本轮只查阅这些论文的摘要，没有复现其结果。

- [Giannakis & Majda, NLSA](https://arxiv.org/abs/1202.6103)
- [Comeau et al., low-frequency North Pacific prediction](https://arxiv.org/abs/1509.05332)

本轮已明确：理想算子的公式、零空间、低阶乘子、原示例的坐标解释缺口。
仍未知：该谱在目标区域是否携带增量预测信息、需要哪些补充观测、可用资料长度、
与基线相比的真实技巧，以及任何半年时效的可用性。

适合下一轮的原问题是：**在固定目标与预算下，当前谱混淆的状态中，哪些会产生
不同的目标未来；最少增加什么观测，才能把它们分开？**

## 9. 用户提出的后继：用 frame 的 i 表达奇偶双通道

同日用户提出：frame 中的 `i` 或许可用于奇数阶，并要求尝试原生表达。
已完成一个[有限原生试算](../experiments/sphaera-frame/README.md)：
保留原核 `sign(a·r)(a×r)`，增加奇核 `|a·r|(a×r)`，把两份观测放在
Adva 的两个 `Real` 输出端口，以原生程序执行 `J(E,O)=(-O,E)`。
Rust 编译器生成实际 `GraftFrame`、来源/复制历史与证书。

16 点有理球面样本上，一阶与三阶旋转场分别从原通道的零响应变为新通道的
`42/125` 与 `−441/625`；二阶的原响应保留。
负对照同时确认：先丢弃奇数阶再乘 `i` 无法恢复信息。
本轮改进是增加了可区分的观测，`i` 承载两通道之间的结构。
通用原生复数 frame 类型、完整球面积分和季节预测技巧仍未建立。

## 10. 重启后续：删去奇数阶与长期结构

用户进一步提出：丢掉奇数阶，尤其一阶，是否反而消去缠绕、留下长期本质？
已完成[独立后继笔记与精确动力学试算](sphaera-parity-and-long-memory.md)。
在一个球面无黏旋转流的精确家族中，两条轨迹拥有相同初始原谱，
但不同的一阶旋转令未来原谱不同；与此同时，形状强度保持一致。
这将“去相位以观察持久形状”与“删去控制移动的一阶动力量”区分开。
新增 305 项检查、42 次原生求值；没有执行真实气象回报。
