## §1 结论（先写判据，再写读数）

1. **C-1 对矩阵方法不成立，而且不是口径造成的。** 球谐阶阶梯的判据曲线在**5 个口径 × 4 本账**下
   argmin 一律落在 **d=16（阶梯上界端点）**，无内部最优、单调。E1 诊断出的两处缺陷（系数按未编码
   64 位计、缺泛化项）**都修掉之后退化依旧** ⇒ 退化不是记账疏漏，而是「词汇表规模 × 每系数成本」
   这种记账形式的性质（见 §4）。
2. **C-1 对原生对象部分成立，但「对口径扰动稳健」不成立。** 可分辨性阈值 θ 的判据曲线：
   `C-5 θ*=10`、`D-10 θ*=50`、`M-2p5-uniform θ*=50` 是**内部最优**且**四本账一致**；
   而 `A-native`、`B-2p5` 的全局 argmin 落在 **θ=0（端点）**，只有当「被排除格点免费」时才移到
   θ=50。⇒ 有内部最优是**口径相关**的，而且**度量**（面积权重）单独就能把 B 从「无内部最优」
   变成「θ*=50」——不稳的来源不止网格分辨率。
3. **C-4 在本轮数据上不可判定。** 按跑出来的记录：原生非退化不变数 2 ＜ 矩阵 3＋1 ⇒ 不成立；
   把「端点最优」这类退化读数正确标记后：原生 2 ≥ 矩阵 1＋1 ⇒ 成立。**同一批读数，判定随计数规则翻转**
   （§5）。更实质的对比在**决策读数**上：矩阵的读数**不变但退化**（永远取端点），原生的读数
   **有判别力但不稳**（0／0／10／50）。⇒ C-4 量的是「谁更不需要做选择」，不是「谁更强」。
4. **两条副产物**（与 C-1／C-4 无关但值得单列）：
   ① **冻结口径上的观测商近似平凡**：13 条通道里 **10 条只有 1 个类**，只有 `t850`／`q850`／`wind850`
   在**原生混合口径**上有 2 类（在规则网格口径上退化为 1 类）。「由可区分性导出的商」在我们的出货
   口径里几乎退化成单元集——这一条独立于本轮判据，是本项目 `X` 面「被假定的呈现」这一诊断的
   一个可数量。
   ② **§D 在 R1 原生网格上复现了 E1 的独立探针**：ERA5 与 R1 的 2026-02 层压筛选翻转
   850／700／500 ＝ **164／148／1** 格，与 E1 卡里记的数字**完全相同**（E1 用的是另一条代码路径、
   另一套读取）。这同时是整条流水线的一次跨实现核对。

## §2 口径与阶梯

| 口径 | 网格 | 说明 |
|---|---|---|
| **A-native** | 各通道自己的原生网格（`sp`／`t2m` T62 高斯 94×192；`sst` ERSST 2° 89×180；其余 2.5° 71×144） | 出货口径，也是 E1 的口径（⇒ 连续性闸门 G3） |
| **B-2p5** | 2.5° 规则 71×144 | 2.5° 原生通道在此**恒等重网格**（G2① 实测 0.0） |
| **C-5** | 5° 规则 36×72 | 与 B 精确嵌套 |
| **D-10** | 10° 规则 18×36 | 与 C 精确嵌套 |
| **M-2p5-uniform** | 与 B 同网格，面积权重改为**均匀** | 把「度量」那一轴与「网格」那一轴分开 |

阶梯：矩阵呈现 **d ∈ {4,6,8,10,12,16}**（域用冻结硬阈值 θ=0）；原生呈现
**θ ∈ {0,5,10,20,50,100,200} hPa**（加在 `level×100` 之上，阶固定出货阶 d=12）。
θ 就是「可分辨性判据的粗细」：θ=0 即冻结口径用的硬阈值。

**共同通道集**：曲线一律只在**逐档都成功**的通道上求和（全局共同集：P1 13 条、P2 10 条）。
15 条失败全部是 `θ=200` 档上 `t850`／`q850`／`wind850` 的 `Insufficient domain`——阈值抬到 200 hPa
时这三条通道的可用域小于词汇表所要求的格数，`masked_project` 依约拒算。这是**判据自己撞到的边界**，
不是脚本崩溃。

| C-5 | −8.852e7 → **−1.396e8** | −9.35847e7 → **−9.35992e7(θ=10)** → −9.02579e7 | 16（端点）／**10（内部）** |
| D-10 | −1.821e7 → **−4.166e7** | −2.41903e7 → **−2.42100e7(θ=50)** → −2.34995e7 | 16（端点）／**50（内部）** |

内部最优的幅度很小：C-5 的 θ*=10 相对 θ=0 只省 **1.45e4 位**（相对 1.5e-4），D-10 的 θ*=50 省
**1.96e4 位**。**限度**：这不是「θ=10 或 50 就该出货」的依据，只是「判据在这一档上有内部极小」的读数；

A-native／B-2p5 的曲线**并非单调**：两口径在 **θ=50 都有一个局部极小**（A: −4.7340e8 对两侧
−4.7310e8／−4.7169e8），只是全局最小仍在 θ=0。⇒ 只看一个 argmin 会漏掉判据的形状，两种读法都记下。

## §4 四种账目：判定是否随「账怎么记」而变

单位归一（每通道除以自身训练期标准差）后，E1 的两处缺陷都补上了，但补丁本身带进一个**未声明的自由
选择**：共享词汇表（`p×64`，只付一次）要不要与「每月每个系数的高斯码长」并计？于是跑完后补了三本
对照账（都在同一批冻结读数上重算）：

| 账 | 每月系数高斯码长 | 共享词汇表 p×64 | 归一残差 | 无免费格点（被排除格点按气候态计费） |
|---|---|---|---|---|
| **A（主账）** | ✓ | — | ✓ | ✓ |
| **B（副账）** | ✓ | — | ✓ | — |
| **C（E1 结构，单位归一）** | — | ✓ | ✓ | ✓ |
| **D（全账）** | ✓ | ✓ | ✓ | ✓ |

argmin（阶／θ）在四本账下的结果：

| 口径 | 账A | 账B | 账C | 账D |
|---|---|---|---|---|
| A-native | 16 ／ 0 | 16 ／ **50** | 16 ／ 0 | 16 ／ 0 |
| B-2p5 | 16 ／ 0 | 16 ／ **50** | 16 ／ 0 | 16 ／ 0 |
| C-5 | 16 ／ **10** | 16 ／ **10** | 16 ／ **10** | 16 ／ **10** |
| D-10 | 16 ／ **50** | 16 ／ **50** | 16 ／ **50** | 16 ／ **50** |
| M-2p5-uniform | 16 ／ **50** | 16 ／ **50** | 16 ／ **50** | 16 ／ **50** |

两条读数：
- **矩阵侧与账目无关**：四本账、五个口径，argmin 一律在 d=16。**退化是结构性的**。诊断：
  在单位归一的高斯码下，系数分账的**幅度**随 d 单调增大、残差分账单调减小（实测 5/5 口径；
  见 `summary.json` 的 `refine_monotonicity_detail`），两项**同向** ⇒ 永远不会出现内部极小。
  注意系数分账在本记法下是**负值**（每个系数的码长记为相对单位参考的收益），这正是 E1「系数太便宜」
  那条诊断在单位归一后的新形态：把每系数成本写死为 64 位并不改变方向，只是把它的量级说大了。
- **原生侧与账目部分相关**：三个「内部最优」口径（C／D／M）在四本账下一致；两个最细口径
  （A／B）只在「被排除格点免费」时有内部最优。⇒ 「域越小越好」的那一侧由**无免费格点**这一项压住；
  去掉它，细网格上可能出现「一路排除到底」的假最优。

计数：**按记录** 矩阵非退化不变数 3、原生 2 ⇒ 不成立；**修正退化标记后** 矩阵 1、原生 2 ⇒ 成立。
翻转的原因是 `run_caliber.py` 把档位 `[16, 0]` 与整数 `16` 相比（与预测 P1 的检查式同型 bug），
端点最优因此漏标两条。**结论按读数的实质写，不按计数写**：

> 决策读数上，矩阵方法**不变但退化**（四口径都取端点 = 不需要做选择），原生方法**有判别力但不稳**
> （θ* 随口径与度量移动）。C-4 的数法奖励退化：任何「永远取端点」的读数都天然不变。
> 因此 C-4 作为换代判据在本轮**不能判定原生方法更强**；它能判的是「谁更不需要做选择」。

## §9 限制与未做（如实列出）

1. **机制未直测**：§4 的解释（细网格上近阈值格多而单格收益小、粗网格／均匀权重下少而毒）目前只是
   **假设**；要变成读数需逐格残差分布 + 边际格与气候态码长的逐格对照（未做）。
2. **内部最优的幅度很小**：C-5 省 1.45e4 位、D-10 省 1.96e4 位（相对 1e-4 量级），换账／换口径即变。
   **不得**据此说「θ=10 或 50 是最优阈值」。
3. **ERA5 的训练期域未重算**（432 个月），§D 只覆盖当月筛选。
4. **只测了「呈现」的判据**，没测预报技巧轴；C-1／C-4 的结论限于记账口径。
5. **口径 A 与 B／C／D 的气压路径不同**（插值 vs 保守重网格）⇒ A 与其余口径的差异里混着这一条。
6. **商近似平凡**（10/13 条通道 1 类）⇒ N1 这类「破坏可区分性」的对照在本数据上几乎空转。
