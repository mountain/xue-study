## 1. 前置检查通过了 —— 关键是 `encode` / `decode`

上一件三次失败的原因是**重建式错**。读 `experiments/multivariate-refinement/model.py`
（不是反推归档）后拿到真实公式：

```python
class SeasonalState:
    def encode(self, c, months): return (c - self.climatology[months]) / self.scale
    def decode(self, x, months): return x * self.scale + self.climatology[months]

def predict(x, targets, vectors, maps):
    return np.stack([(x[targets-lead] @ vectors) @ maps[lead-1] for lead in range(1, 7)])
```

以及 `train.py`：
- `x = state.encode(c, months)`，`select`/`predict` **都吃编码态**
- `learned = predict(x, test, vectors, maps)` 是**编码态**的预报
- `physical = {name: state.decode(p, months[test]) ...}` ⇒ **`backtest.npz` 存的是解码后的**
- `aggregate` 拿 `x[test]` 比 ⇒ 技巧在**编码空间**里评

**验证结果**：按此公式复现 `backtest.npz['joint']`，最大绝对差 **4.547e-13**、相对 **4.49e-18**
—— 逐点一致。前置检查通过。

（此前失败的三个原因，按时间顺序：① 键归错了文件；② 漏 `encode`；③ 漏 `decode`。）

## 2. 检验设计

用**模型自己的预报误差**作为被预报对象 —— 这是唯一还能增强的通道：

1. 取 E/O 相对模型状态 `x_enc @ vectors` 的残差（训练期 ≤2014-12 拟合，两侧按日历月去季节）。
2. 在训练期上，用残差线性拟合**模型的预报误差** `x_enc[t+k] − (x_enc[t]@vectors)@maps[k-1]`。
3. 在开发回测期（2020-01…2025-12，72 月）应用，看技巧变化。

全程在**编码空间**里评（与 `train.py` 的 `aggregate` 同空间）。

## 3. 结果：六个 lead 全部劣化

| lead | 基线技巧 | +E残差 | +O残差 | +E+O残差 | **Δ(E+O)** |
|---|---|---|---|---|---|
| 1 | 0.1341 | 0.1301 | 0.1297 | 0.1256 | **−0.0085** |
| 2 | 0.0910 | 0.0888 | 0.0905 | 0.0881 | −0.0029 |
| 3 | 0.0795 | 0.0775 | 0.0749 | 0.0726 | −0.0070 |
| 4 | 0.0689 | 0.0680 | 0.0659 | 0.0642 | −0.0047 |
| 5 | 0.0642 | 0.0619 | 0.0570 | 0.0535 | −0.0106 |
| 6 | 0.0596 | 0.0592 | 0.0557 | 0.0545 | −0.0051 |

**结论：E/O 的残差不能增强 L12 全球测试。六个 lead 全部劣化，无一处改善。**

**机制读法**：修正是拿训练期误差拟合的，**在训练期按构造必然改善**，在样本外**一致劣化**
⇒ 训练期里「残差 ↔ 模型误差」的关系**不泛化**。这比「没信息」更准确：
**它没有关于模型误差的可泛化信息。**

这与上游冗余探针一致：模型状态已解释 E 的 71.2%、O 的 87.4%，剩下的残差不但无用，还有害。

## 4. 限制

**一、未做显著性检验。** Δ 在 72 个回测月上算，相对劣化 2%–17%（lead 1 为 6%）。
**没有算置信区间**，故不得引用具体幅度为「效应大小」，只能说**方向一致为劣化**。

**二、没有试非线性或更多预报子。** 只试了训练期线性修正。若有人主张「换个形式就能增强」，
**本件不支持也不排除** —— 但按冗余读数，先验是悲观的。

**三、L12 的 `model_role` 是 `reference`**，且 `prior_exposure` 如实写明 2020–2025 被看过
⇒ 以上一切**只能叫开发回测**，不得称独立验证。

**四、没有按 ADR 0004/0006 写契约。** 本件是**诊断性检验**（用 native 通道去解释矩阵模型的误差），
不是把 native 通道接进模型的产出。若有人要真接进去，**必须先声明呈现层身份并保留显式残差**。
