“背景”是我们自己从 NOAA NCEP/NCAR R1 月 u/v 场算出的 1979—2014 逐月平均向量及其谱投影。NOAA 没有给出“这三地的变化只是季节噪音”的结论。两个原始 NetCDF 的 SHA 与采集凭据一致，独立读出 500 hPa 后与 NPZ 逐值完全相同。固定同一位置的一月原生平均向量模为 37.661 / 28.483 / 23.123 m/s；L12 背景为 38.091 / 28.338 / 21.339；L12 预报为 38.052 / 29.395 / 21.452。原始月 u/v 序列、坐标、单位、URL 和 SHA 全部保留。

纠正前一步的推理范围：预报本来按“谱气候态＋学习距平”构造，将预报指回该气候态首先说明内部数值分解，不能独立证明大气的机制；均值中的三中心也不能排除距平中的远程耦合。季节相位结构不是随机噪音；扣除月平均是一个统计观察选择，不是物理解除耦合。

本轮固定区域框后读取 1979—2025 的 564 月原始再分析：区域平均风矢量模的三对原始相关为 0.847 / 0.928 / 0.850；扣除各自训练期日历月均值后为 −0.061 / 0.101 / 0.044（顺序为东亚—北美、东亚—中东、北美—中东）。1999 次 24 月分块区间均覆盖零；相位随机零假设经三重 Holm 校正为 0.330 / 0.0705 / 0.330，整年循环移位控制也保留。方法依赖平稳性等近似，未把不显著当作不存在的证明。
