# 2026-10-08 · 把「零需要两种不对称」搬到链式外推上

**性质**：一次**结构性判定 + 一次交叉核对**，落在本仓库自己冻结的读物上。
**不重跑任何东西**；不修改冻结件。

**源**：
`archive/multivariate-chained-reforecast-v1/report.json`（冻结读数，sha256 见其自身字段）、
`experiments/multivariate-chained-reforecast/contract.json`（跑前冻结，`c717efe8…`）。

**要回答的**：adva 0242 的判据是「净输运需要空间与时间**两种**不对称同时在场」。
链式外推**不输运**（它收缩到气候态）。那么它落在 0242 四组态中的哪一格 ——
是**对称性导致的零**，还是别的？

---

## 1. 链的配置：先把它翻成 0242 的语言

0242 的模型由四样东西构成：环上的势 `U`（**空间**结构，带一个声明的钉扎位）、
门函数（只读斜率**符号**）、相位梯度 `g`、以及一个**随时间变化**的排程 `ν_s`（**时间**结构）。

链式外推由契约定义（`design.operator` 原话）：

```
M1(x) = (x @ vectors) @ maps[0]     —— 与冻结代码同一算式同一顺序
（不预先乘成 vectors@maps[0]，避免结合律带来的末位差异）
```

⇒ **每一步用的是同一个 `maps[0]`。排程是恒定的。**

| 0242 的构成 | 链式外推的对应物 |
|---|---|
| 环上的势 `U`（空间结构） | **无**。链是系数空间上的线性映射，没有环、没有势、没有钉扎位 |
| 门函数（读斜率符号） | `vectors`（投影到 EOF 基，降秩）＋ `maps[0]`（岭回归映射） |
| 相位梯度 `g` | **无** |
| 排程 `ν_s`（时间结构） | **恒定**：`maps[0]` 在每一步相同 |

**恒定排程满足 `ν_{3-s} = ν_s`，即回文。** 而 0242 声明的时间**非**对称是
「反对称摇动」（antisymmetric rocking），不是回文。

⇒ **链的驱动落在「时间对称」那一列。**

---

## 2. 判定

按 0242 的四组态表：

```
R1  空间对称 + 时间对称    →  0
R2  空间非对称 + 时间对称   →  0     ← 测度非均匀，流仍精确配对
R3  空间对称 + 时间非对称   →  0
R4  两者兼有               →  非零
```

**链在「时间对称」的一列**（R1/R2）。**而 R1 与 R2 的输运都恰为零，
与空间是否对称无关。**

> **⇒ 链不输运，是结构上的，不是参数没调好的。**

**但它比 R1/R2 还要早一步失败。** 见下。

---

## 3. 链失败在更前面：它的不变测度是**退化的**

0242 与 0245 的整个框架都预设了**一个非退化的测度**在环/图上被输运。
链没有这个前提：

```
σ_max（幂迭代 60 步，冻结读数）= 0.8244 < 1   ⇒  严格收缩
⇒ 任何初值分布被推前算子反复作用后收敛到【点质量】（异常空间的原点）
⇒ 不变测度【唯一】且【退化】
```

**这不是「两种不对称都有、只是相消」，而是「根本没有可输运的测度」。**

| | 0242 R1–R3 | 链式外推 |
|---|---|---|
| 不变测度 | 非退化（环上分布） | **点质量** |
| 零输运的来源 | 每步流**精确配对**相消 | **测度本身不动** |
| 失败的层次 | 对称性 | **在输运被定义之前** |

---

## 4. 交叉核对：幂迭代的 σ_max 能否预言实测衰减

冻结报告里有逐步的 `step_gain` 与 `max_abs_z`（十步的粘合台账）。
把 σ_max 拿去预言：

| 2 | 0.6247 | 0.8244 | −0.1997 | 0.8104 | 0.9747 |
| 3 | 0.7781 | 0.8244 | −0.0463 | 0.6110 | 0.8035 |

| 10 | 0.8263 | 0.8244 | +0.0019 | 0.1586 | 0.2080 |

**两条读数：**

1. **第 2 步起，实测增益稳定在 0.8256–0.8267，与 σ_max 一致到 0.23%。**
   链确实在沿着主奇异方向衰减 —— 幂迭代的估计**被独立核对通过**。
2. **第 1 步的增益只有 0.3188**，远小于 σ_max。⇒ 2026-02 那个**特定**方向被压得特别狠。
   这是一个**起点相关**的事实，不是算子的一般性质。

（第 10 步实测 0.1586，σ^k 预言 0.2080）。

**这不是矛盾，是量不同**：`σ_max` 是**最慢**衰减方向的速率，而 `max|z|` 混合了所有分量，
快分量拉低了它。**两者不可互相替代引用。**

## 5. 对 ensemble 的直接含义（这是本件的目的）

把 0245 与链并置，得到**两种相反的失效**：

| | 不变测度 | 初始化的地位 |
|---|---|---|
| **0245**（分量 8/4/4/4 不连通） | 精确平稳但**不唯一** | **决定**你坐在哪个不变测度上，且**欠定** |
| **链式外推**（σ_max 0.824，严格收缩） | **唯一**且**退化**（点质量） | **被彻底遗忘** |

> **「初始化不重要」在链这里不是一个优点，是一个症状。**
> **一个初值不影响的系统，是一个不能承载预报信息的系统。**

这正是你说「初始化难题显然且传统」时那个难题的**另一个极端**：
传统 ensemble 的困难是「初值影响太大且欠定」；链的困难是「初值完全不影响」。
**两者都不可用，但方向相反。**

### 由此得到的三条设计判据

一个**能承载 ensemble** 的算子应当同时满足：

1. **不变测度非退化** —— `σ_max` 不得把一切压成点质量（即算子不能是纯收缩）
2. **排程不得恒定** —— 需要**时间不对称**（回文排程输运恰为零，与空间结构无关）
3. **必须有空间结构** —— 需要**空间不对称**（0242 的 R1 与 R3 说：缺了它也是零）

**链式外推三条全不满足。** 而它给出「气候态」这件事，是这三条同时缺失的**推论**，
不是一次可以靠调参改善的偏差。

## 6. **本篇的可证伪形式**（以及它现在卡在哪）

**0242 明写**：那些零「是关于**这个**声明模型的陈述，**不是**关于任何物理系统的定理」。
所以我**不能**说「0242 证明了链不输运」。本篇的主张是**一个假设 + 一个判据**：

> **假设**：链的驱动是时间对称的（恒定排程 ⇒ 回文），因此按 0242 的 R2，
> 其输运应当为零，且这与空间结构无关。
>
> **判据（会否证它）**：把链的排程从恒定改成**非回文**（例如两步交替），
> 若输运**仍然为零**，则「时间不对称是必要条件」在这套对象上**不成立**，
> 本假设被否证；若出现了原本没有的持续性／输运，则假设得到支持。

**另一条判据**：把算子分解为对称部分与反对称部分。
若反对称部分为零，或加上一个非零反对称部分**不改变任何读数**，则 0242 的语言不适用。

**卡点（如实说）**：**冻结的 `model.npz`（`vectors` / `maps`）不在本机** ——
它在远端 `/home/ubuntu/xue-study/archive/multivariate-l12-v1/`。
S3 异地备份存在，但取用需要 `XUE_BACKUP_BUCKET` 环境变量与 aws CLI。

⇒ **上面两条判据目前都跑不了。** 本篇只交结构性判定与交叉核对，
**不声称做了那个实验。**
