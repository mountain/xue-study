## 1. 两份各建立了什么

### 0242：净输运需要两种不对称同时在场

六点环，声明的反射、两个声明势（对称 / 非对称且带唯一**钉扎位**）、
门函数**只读斜率符号**、相位梯度 `g ∈ {−1,0,+1}`、四步声明排程。全部精确求解：

| 组态 | 输运 |
|---|---|
| 空间对称 ＋ 时间对称 | **恰为 0**（测度均匀；每步流 `3/16, 0, −3/16, 0` 精确配对） |
| 空间**非**对称 ＋ 时间对称 | **恰为 0**（测度**非均匀**；流仍精确配对） |
| 空间对称 ＋ 时间**非**对称 | **恰为 0**（每步流恰为 `(3/8)ν_s`，故输运 ＝ `(3/8)×`排程均值 ＝ 0） |
| **两者兼有** | **非零** `∓2395373021828541/130893752065903472383`，反号精确反向、两向之和恰为 0 |
| 驻波 `g=0` | **0**，且转移退化为均匀扩散 |

**每一个零都是「对相应断言的执行式否决」，不是一句话。** 其中配对对照最有判别力：
**同一个非对称势**，配时间对称排程恰为零，配时间非对称排程非零。

### 0245：一个精确平稳的携测度后继

二十顶点图，转移 `P_s(g) = B + (a_s g/16)·C`，`B = (I+A)/4`，`C = K − RKR`。
逐步**双随机**（两个边缘恰为一），均匀测度 `u_i = 1/20` **精确平稳** `uP_s = u`，
顶点质量散度**恒为零**。检查器**真的推进状态**、保留全部五个态、不重置不归一。

可观测量是固定的斜边观测量 `D = C`：

```
J_s = Σ_{i,j} μ_s(i) P_s(i,j) C_ij = a_s g / 20
```

**而这一条是全部的关键**（0245 §5 原话的意思）：

> 对任意单值顶点函数 `f`，平稳性强制 `Σ u_i P_ij (f(j) − f(i)) = (uP − u)f = 0`，
> **也意味着任何割面上的净质量穿越为零**。非零的那个可观测量**不是端点梯度**：
> 它沿方块积分等于四 —— 它数的是**有向路径环流**。
> **没有建立任何非零的欧氏位移或物质输运。**

## 2. 两份共用的机器：周期测度、秩唯一性、流而非测度

这是我认为最有移植价值的一层，也是两份一致的写法：

**① 测度按构造是周期的。** 0242 声明的测度是
「声明转移在**恰好一个声明周期**后重现的**唯一**测度」，精确求解。
因此每一组的 `final_minus_initial` **全是 0** —— **最终态恒等于初始态**。

**② 输运不在测度里，在未缠绕的流里。** 0242 的输运定义为

```
net displacement = Σ_s J_s,   J_s = Σ_i (A_s(i) − B_s(i)) · p_s(i)
```

即「沿声明环的**未缠绕**位移」。**测度不动，流可以非零。** 0245 同构：
`J_s = Σ_{i<j}[μ_i P_ij − μ_j P_ji] C_ij`。

**③ 唯一性是一个秩条件。** 0242 明写：唯一性「由声明周期转移减去单位阵的**精确秩**判定」。

> **这一条是整份研读的分水岭。** 两份的差别不在精度，在**这一个秩**。

## 3. 两份恰好在初始化这一轴上分岔

| | 0242 | 0245 |
|---|---|---|
| 图 | 六点**环**，连通 | 二十顶点，**分量 8 / 4 / 4 / 4** |
| 周期测度 | **唯一**（秩条件判定） | 精确平稳但**不唯一**：分量质量可变 |
| 收敛声称 | 测度本身即周期测度 | **不**声称全局混合、**不**声称从任意初值收敛到均匀 |

**这就是 ensemble 初始化难题的精确位置。**

- 0242 的情形：状态空间连通 ⇒ 不变测度唯一 ⇒ **初值只影响暂态，不影响归宿**
- 0245 的情形：分量不连通 ⇒ 不变测度**不唯一** ⇒ **分量之间的质量由初值决定，而且一旦定下就永久保持**

**⇒ 初始化的难点不是「怎么给初值」，而是「初值落在哪个分量上、带多少质量」。
后者不被动力学决定。**

这与传统 ensemble 的困难是同一件事的两种说法：模式有多个平衡态／吸引子时，
**集合的初始化决定了你坐在哪一个不变测度上**，而那个权重**不是从动力学推出来的，
是你放进去的**。0245 把这句写成了一条可检验的性质（秩），而不是一句警告。

## 4. 对 ensemble 的五条可移植读数

### ① 平稳的集合不输运任何东西 —— 而且这与离散度无关

0242 的三个零（R1/R2/R3）**全部是测度平稳、输运为零**的情形。
⇒ **「我的集合是平稳的／校准良好的」不蕴含「它把信息往前带」。**

**这是对 ensemble 最直接的一条**：集合的价值在于**输运**，而输运需要
**空间结构**（介质的不对称）与**时间不可逆**（驱动的不对称）**同时在场**。
只有一样时，输运**恰为零** —— 不是「小」，是零。

### ② 双随机不蕴含零环流

0245 明写：双随机本身推不出排程对称或零环流；**破缺排程也是双随机的，却携带 1/10**。

⇒ 换成集合语言：**「集合守恒总质量／无净漂移」比「转移具有所需的对称性」弱**。
一个精确保概率的集合**仍然可以携带非零流**。**守恒 ≠ 可逆。**

### ③ 输运可能只读符号结构，不读幅度

0242 有**一条未能判别的对照，被保留而非修好**：
把声明势整体乘 3，门、转移与输运**完全相同** —— **因为门只读斜率的符号，势的幅度从不进入转移。**

⇒ 若这条在别处也成立，则：**加大集合离散度（幅度）不改变输运，改变的只有符号结构。**
这是一个尖锐的、可证伪的、而且与直觉相反的说法。**0242 只声明它在这一个模型里成立。**

### ④ 约定必须在接口显式转置

0245 §4：0242 的 R4 周期测度是**非均匀**的，其**列随机约定在比较边界上被显式转置**；
把它当作均匀平稳候选交上来，**第一步就被拒，漂移 ±1/96**。

⇒ 把不同来源的集合分量拼起来时，**行随机 / 列随机必须在接口显式转置**。
一个纯约定错误会产生一个量得出、看得见的漂移。

### ⑤ 唯一性要当成一个被检验的量，而不是默认

`0242` 把「测度唯一」列在 `checks` 里，与「测度被精确重现」并列，都打了勾。
`0245` 则把它列为**残余**。**同一件事，在一处是检查项，在另一处是残余项。**

⇒ 在 ensemble 里，「我的不变测度唯一吗」应当是一个**显式检查**，
而不是一个默认假设 —— 因为答案决定初始化到底重不重要。

## 5. 这两份**没有**给的东西（必须同时说）

1. **没有数据、没有物理量。** 0242 自述：「不输送任何物质，不烧蚀、不融化、不移动、不加热，
   对任何物理量**不声称幅度、符号或时间**，不读也不使用数据。」0245 同。
   两者都是**声明的离散模型**，换一个环／势／驱动／周期／门规则就是另一次运行。
2. **没有定理化的迁移。** 0242 明写这些零
   「是关于**这个**声明模型的陈述，**不是**关于任何物理系统的定理」。
3. **无限维、连续状态空间、真正的大气都没有涉及。** 有限精确是可核对的代价，
   不是可迁移的保证。
4. **初始化本身没有被解决。** 0245 只是**拒绝声称**从任意初值收敛 ——
   它把难点的位置**指出来了**，没有把它移走。
5. **0242 另有六条 `Undecided`**（门规则是否是本意的势—转移关系、梯度是否应取更大范围、
   均匀参考测度是否应当是输运测度、时间对称应读作反对称摇动还是回文排程、
   步能量是否该叫能量、这些零是否对别的环／周期／步长成立）。

## 6. 若要往下走，可证伪的几条

按代价从小到大，且每条都写明**怎么做才算证伪**：

1. **把「零需要两种不对称」搬到本仓库已有的对象上**：我们已有链式外推
   （每步增益 0.826，两步内信息耗尽）。问：那条链的转移**有几种不对称**？
   若它两种都不是，则「不输运」就不是参数没调好，而是**结构上就不该输运** —— 可证伪。
2. **检验 ③（只读符号，不读幅度）在别处是否成立**：把一个已知输运的算子的幅度整体缩放，
   看输运是否不变。**不变 ⇒ ③ 不限于 0242 的一个模型；变 ⇒ ③ 是那个模型的特性。**
3. **把「不变测度唯一吗」变成一个显式检查**：对链式外推的转移阵算 `P − I` 的秩，
   看分量质量是否被唯一确定。这直接回答「我们的初始化到底重不重要」。
4. **不做的**：不把上面任何一条写成「我们建立了集合预报的测度论」。
   0242/0245 的分量是**精确有限模型**；我们的分量是**一个收缩的线性链**。两者之间的桥，
   本步没有建。

## 7. 一句话

> **0242 说：平稳不等于输运，输运要两种不对称同时在场。**
> **0245 说：平稳可以精确，但在不连通的状态空间上它不唯一 —— 而分量质量由初始化决定。**
>
> 合起来对 ensemble 的意思是：**集合的用处不在它平稳，在它输运；而它坐在哪个平稳测度上，
> 是一个初始化问题，不是一个动力学问题。**
