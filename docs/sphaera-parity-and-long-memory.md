# 丢掉奇数阶，是否更接近长期结构？

日期：2026-09-24。作者：Codex（OpenAI）；问题与研究方向：用户。
接续 [谱定义与原生 frame 试算](sphaera-seasonal-spectrum-theory.md)。

**结论：可能有利，但要按预测目标判断。当前已得到一个精确例子：忽略一阶后，
形状强度仍可长期确定，形状未来的位置却不能由当前原谱唯一决定。**
这把“去掉缠绕”变成了可检验的问题：哪一种相位可以忽略，哪些慢变量仍须保留？
这里的“缠绕”没有被定义成拓扑缠绕数，本轮不声称证明了任何拓扑消结。

本文的奇偶阶始终指球谐的空间次数 ℓ，不是时间导数阶数，也不是统计矩的阶数。
当前工作为理想模型推导、符号核对和有限原生算术；没有气象回报或半年预测结果。

## 1. 三种不同的简化

1. **去奇数阶**：原谱的涡度卷积核为 `|a·r|`，奇数 ℓ 的乘子为零。
   这保留一个有损的空间表示，不自动选择衰减慢的时间模态。
2. **忽略整体方位**：把旋转后视为相同形状，或直接计算旋转不变量。
   原谱本身没有做完这件事；风场转动时，谱图也会转动。
3. **减少估计负担**：有限训练样本下删去无关通道，可能降低过拟合。
   这是统计泛化收益，需要独立年份验证，不等同于信息增加。

因此，原谱消去刚体旋转场，与对一般风场的旋转轨道取商，不是同一个算子。
例如原谱看不到叠加的 `w e_z × r`，但仍会分辨朝向不同的二阶图样。
“偶数阶”也不等于“低频”：它保留高空间次数的偶数模态，同时删除最大的非平凡
空间尺度 ℓ=1。仅据次数奇偶无法比较时间尺度。

## 2. 同一个精确流动，同时给出正例与反例

在单位球面，规定

\[
u=r\times\nabla_S\psi,\quad \zeta=\Delta_S\psi,\qquad
\partial_t\zeta+\{\psi,\zeta+2p z\}=0,
\]

其中 `p` 为规定的行星自转参数，
`{f,g}=r·(∇f×∇g)`，模型无外力、无黏性、无辐散。
考虑

\[
\psi=-wz+A(t)(x^2-y^2)+2B(t)xy.
\]

第一项是 ℓ=1 的刚体式旋转，后两项属于 ℓ=2。
直接代入方程得到

\[
\dot w=0,\qquad c=\frac{2w-p}{3},\qquad
\dot A=-2cB,\quad\dot B=2cA.
\]

取 `A(0)=1,B(0)=0`，有 `A=cos(2ct), B=sin(2ct)`。
形状以角速度 `c` 转动。这是 Rossby–Haurwitz 解的一种受限形式。
文献给出的对应相速为 `α(1/2−1/[ℓ(ℓ+1)])−p`，
代入绝对涡度一阶系数 `α=2(w+p)` 与 `ℓ=2` 即得上述 `c`。
相关研究还区分了逐点稳定与容许旋转后的轨道稳定。
[Cao、Wang、Zuo，原论文 §1、§2.3–2.4](https://arxiv.org/html/2305.03279v2)

原谱的理想连续读数为

\[
E(a,t)=-\frac34\left[A(t)(a_x^2-a_y^2)+2B(t)a_xa_y\right].
\]

它不含 `w` 的直接读数，但 `w` 决定了 `A,B` 的未来。
取 `p=0`，对比 `w=0` 与 `w=3/2`：

| 观察目标 | 初始，两条轨迹 | t=π/4，w=0 | t=π/4，w=3/2 |
| --- | --- | --- | --- |
| 固定轴 `a=e_x` 的连续谱 E | −3/4 | −3/4 | 0 |
| 整个二阶谱的归一化平方积分 | 3/20 | 3/20 | 3/20 |

两条轨迹**完整的初始偶谱**相同；之后完整偶谱不同。
这给出固定位置目标的确定性闭合反例，不只是三个采样轴的偶然重合。
另一方面

\[
\frac1{4\pi}\int E(a,t)^2d\Omega_a
=\frac3{20}(A^2+B^2),\qquad
\frac d{dt}(A^2+B^2)=0.
\]

对于这个形状强度目标，未知 `w` 无碍预测。这是用户猜想的一个明确成立范围。
但它是恒定目标的精确例子，没有证明一般非平凡慢变量的可预报性。
若目标是固定地区的月平均状态，还须检查时间平均后的条件分布；这里的单轴反例
不能直接判定某个地区的温度、降水或半年技巧。

这些时间均为无量纲时间，不能把 `π/4` 或图中的横轴解释为月份。
另见 [算例图](../experiments/sphaera-parity-dynamics/runs/run-001/phase-and-shape.svg)。

## 3. 一阶可能恰好携带长期记忆

在本算例，归一化角动量和动能分别为

\[
\langle r\times u\rangle=(0,0,2w/3),\qquad
\frac12\langle|u|^2\rangle=\frac{w^2}{3}+\frac45(A^2+B^2).
\]

`w` 是常数；把一阶删掉会隐藏这个守恒量，也会隐藏传播速度。
“特别是一阶是短时干扰”在这里不成立。
旋转球面 Euler 方程的一阶投影存在相应守恒或可确定旋转关系，见上述论文 §2.4。
真实大气有力矩交换、地形、热力过程和海陆耦合，不能把这个守恒结论直接搬过去。

更一般地，**只保留偶数阶也通常不构成封闭动力学**。
在本方程取 `p=0`，初始流函数为

\[
\psi=(x^2-y^2)+(x^4-6x^2y^2+y^4),
\]

两项分别是二阶、四阶，初始均为偶函数。精确计算却给出

\[
\partial_t\zeta=-224xyz(x^2+y^2),
\]

这是非零奇函数。在单位球面点 `(1/3,2/3,2/3)`，值为 `−4480/243`。
于是每一步都强制把奇分量清零，会改变这个模型的演化。
这不排除有效的约化模型，只说明必须说明遗漏分量的反馈、历史或统计闭合。

## 4. frame 的 i：现在有一个更具体的用途

上一轮在奇偶观测对 `(E,O)` 上定义 `J(E,O)=(-O,E)`。
它表达两份观测之间的算术结构，不能凭此推出物理演化。

这一轮的**另一对坐标**是二阶内部的余弦、正弦系数 `(A,B)`：

\[
C_2=A+iB,\qquad \dot C_2=2ic C_2.
\]

在这个已核对的模型中，`i` 是相位演化的生成结构；模长代表形状强度，
`w` 通过 `c` 决定相位转动。原生程序复用了 `turn-i` 计算这条方程的右端。
**`(A,B)` 都属于偶数 ℓ=2；它们不是上一轮的 `(E,O)`。**
相同的二维矩阵，必须绑定各自的坐标解释，不能混同两种载体。

这启发一种下一步表示：**形状变量 + 相位/参考架 + 少数驱动量**。
目标若不关心方位，可以对形状评分；目标若落在固定地理区域，须保留与地理方位的关系。
即便移动参考架令图样静止，也必须保存参考架如何移动，才能恢复地理预报。
真实地球的地形和陆海分布还限制了哪些旋转可视为对称。

对于一般二阶势 `rᵀQr`（`Q` 对称且无迹），`tr(Q²)`、`tr(Q³)` 可作为旋转不变量；
本轮只验证了受限 `(A,B)` 家族的平方模长。这里的三次矩阵不变量不是 ℓ=3 球谐，
不能因名称含“三次”就把它按奇数空间阶删除。

## 5. 什么时候“少看一点”有利？

令 `E` 为偶观测，`O` 为遗漏的奇观测，`B₀` 为共同的季节、慢变量与可用历史，
`Yτ` 为固定的未来目标。理想的无损条件是

\[
\mathcal L(Y_\tau\mid E,O,B_0)=\mathcal L(Y_\tau\mid E,B_0).
\]

该等式只判定给定奇观测 `O` 的增量，不能证明 `E` 对完整大气状态充分。
平方误差下，存在二阶矩时，舍去 `O` 的最优预测风险增量为

\[
R^*_{E,B_0}-R^*_{E,O,B_0}
=\mathbb E\big[\{\mathbb E[Y_\tau\mid E,O,B_0]
-\mathbb E[Y_\tau\mid E,B_0]\}^2\big]\ge0.
\]

这是条件期望的正交分解。因此信息本身不会因删除而增加。
有限数据、有限容量模型中，估计方差可能下降，使实测测试误差改善。
这两种风险必须分开：最优条件风险与实际学习器的泛化误差。

长期时效也不会自动使这个条件成立；慢的奇分量、守恒量和对偶分量的反馈都可能留下作用。
需要观察各提前量的条件增益，而不能把“谱图更平稳”直接当成预报技巧。

## 6. 已执行证据与下一轮对照

[本轮实验](../experiments/sphaera-parity-dynamics/README.md)使用 SymPy 做多项式恒等式核对，
复用上一轮真实 Rust/Adva 编译器、GraftFrame、检查导入与有限求值器。
已通过 **305 项检查、42 次原生求值**，最大原生/有理数参考误差
`2.220446049250313e-16`。旧试算的文件与结果保留。
符号残差为零是外部代数证据，原生结构证书没有认证天气动力学。

后续真实资料实验尚未开始。建议沿原有 1、3、6 个月回报设计，先固定同一目标，比较：

| 表示 | 检验问题 |
| --- | --- |
| 原偶谱 E | 用户的粗粒化假说基线 |
| E + 三个一阶旋转系数 | 少量角动量信息是否补回未来移动规律？ |
| E + 不含一阶的奇观测 | 高阶奇分量是否另有贡献？ |
| E + 全部选定奇观测 | 与上述两种贡献联合比较 |
| 形状不变量，及其加方位/一阶量的版本 | 改善来自忽略相位、缩小容量，还是保留了动力驱动？ |

一阶系数可在理想全球同权观测下由
`w_vector=(3/2)〈r×u〉` 提取。新奇通道 `O` 本身混合多个奇数阶，
比较“一阶”与“更高奇阶”须明确分解；有限采样的混叠先校准。

所有组共用季节、慢变量、历史长度、训练年份和预测器选择流程；预报目标不随表示改变。
补充相同数量特征的普通低阶球谐对照，区分奇偶选择与普通降维。
同时保留两类评分：固定地区目标，以及预先声明的整体形状目标。
如果只在后者有效，结论应限定为形状预报；如果补一阶就明显改善前者，
则优先保留低维一阶驱动，而非一口气把所有奇阶都加回来。

本轮恢复点：理论与两次有限原生实验均已保存；真实数据的区域、变量和平均窗口仍待选定。
